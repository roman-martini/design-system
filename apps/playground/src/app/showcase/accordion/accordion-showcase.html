¿Qué es el design system?

Librerías de arquitectura frontend publicables: tokens con theming y componentes Angular accesibles construidos sobre ellos.

¿Cómo se instala?

npm install @romanmartinidev/tokens @romanmartinidev/components y se importa el CSS de tokens en los estilos globales.

¿Se puede themear?

Sí: los themes redefinen tokens semánticos sin tocar los componentes.

Single: abrir una sección colapsa la anterior. Teclado: ↑/↓ mueven el foco entre headers (con wrap, sin saltear disabled), Home/End van a los extremos, Enter/Space alternan la sección.

Requisitos

Angular 21+, tokens como peerDependency.

 Compatibilidad

Zoneless y signals-first; los componentes son standalone.

Con multiple, cada sección alterna independiente.

 Sección disponible

Contenido normal.

 Sección no disponible

Este contenido no puede expandirse.

El header disabled sigue siendo focusable y expone aria-disabled (descubribilidad por teclado y screen reader); la activación está bloqueada.

Configuración avanzada Tokens

Jerarquía primitives → semantic → component → theme.

 Themes

Un theme solo redefine tokens semánticos.

 Otra sección del padre

La exclusividad y el teclado del anidado no interfieren con el padre.

Cada instancia coordina solo sus secciones: expandir en el anidado no colapsa al padre, la navegación por flechas no cruza instancias y el headingLevel mantiene la jerarquía de headings. Verificar acá la animación de altura (incluido colapsar el padre con el hijo expandido) y prefers-reduced-motion.
