**Reason**: Promovido a la spec `component-button` (aaa-030, split de specs por componente). El contrato no cambia; solo se reubica a la capability del componente.
**Migration**: El contrato de "Tests del Button con Vitest" ahora vive en `openspec/specs/component-button/spec.md` con el mismo texto y scenarios. Los changes futuros de este componente escriben su delta contra esa spec, no contra `components-package`.
