# Catálogo de Specs y Changes

Inventario histórico de las specs vigentes y de todos los changes de OpenSpec. Es un **índice**: crece una fila por change archivado (paso del [checklist de archive](../product/README.md#checklist-de-archive)) y no contiene contratos ni decisiones — para eso están las [specs](../../openspec/specs/), los [ADRs](adr/) y el [decisions-log.md](decisions-log.md). La síntesis técnica vive en [ARCHITECTURE.md](ARCHITECTURE.md).

Convención operativa + próximo ID disponible: [openspec/README.md](../../openspec/README.md).

---
